# Employee Management and Attendance Tracking System

## Description
This is a comprehensive database system designed to manage employee information and track attendance. The system includes:
- Employee details (ID, name, department, job code, contact info, salary, manager)
- Attendance records (time in, time out, status)
- User roles with different access levels (HR Admin, Department Manager, Regular Employee)
- Sample data and queries for testing and reporting
- Indexes for performance optimization

## Features
- Add, update, delete, and view employee records
- Track employee attendance and monitor late or absent statuses
- Role-based access control for different users
- Preloaded sample data for demonstration
- Useful SQL queries for reporting and analysis

## Technologies
- Oracle SQL
- PL/SQL (Sequences, Views, Roles, Indexes)
- SQL Developer or any Oracle Database client
